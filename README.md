# Primary ICT Projects — Enhanced Edition

Three polished, browser-based ICT learning projects for primary-school learners.

## 1. My First Computer Lab
An interactive computer-parts learning activity with:
- Clickable computer parts and explanations
- Fun facts
- 5-question matching mission
- Stars and score tracking
- Instant feedback
- Final achievement screen
- Responsive layout

## 2. ICT Quiz for Kids
A gamified ICT quiz with topic selection, progress, lives, hints, streaks, explanations, achievements and responsive answer cards.

## 3. Creative Drawing Studio
A browser drawing studio with:
- Brush, eraser, line and circle tools
- Custom colour picker and quick colour swatches
- Adjustable brush size
- Undo / redo
- Clear canvas
- Random creative challenges
- Creative points
- PNG save button
- Mouse and touch support

## How to run
Open each project's `index.html` in a modern browser. No installation or internet connection is required.
